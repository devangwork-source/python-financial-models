# Finance Models in Python
This repository contains financial models that I built while learning quantitative finance and financial modeling. The goal of these projects is to apply concepts from finance using Python and understand how different financial models work in practice.
Most models use historical market data and numerical methods to simulate financial outcomes.

## Projects

### Portfolio Optimization (Markowitz Model)

A portfolio optimization model based on Modern Portfolio Theory.

Features:
- Uses historical stock data from yfinance
- Calculates expected returns and covariance matrix
- Simulates multiple portfolios using random weights
- Identifies the portfolio with the highest Sharpe ratio
- Visualizes the risk-return relationship
- 

### Monte Carlo Simulation

A Monte Carlo simulation used to model potential future price paths of an asset.

Concepts used:
- Random sampling
- Geometric Brownian Motion
- Probability-based forecasting
- 

### Black-Scholes Option Pricing Model

Implementation of the Black-Scholes formula to calculate the theoretical price of European options.

Inputs include:
- Stock price
- Strike price
- Time to maturity
- Volatility
- Risk-free rate
  

### Bond Pricing Model

A model used to calculate the price of a bond by discounting future coupon payments and the face value.

Concepts:
- Present value
- Yield to maturity
- Fixed income valuation


### Discounted Cash Flow (DCF) Model

A financial model used to estimate the intrinsic value of a company by forecasting future cash flows and discounting them to present value.


### Leveraged Buyout (LBO) Model

A simplified model demonstrating how acquisitions can be financed using debt and equity and how investor returns are calculated.
